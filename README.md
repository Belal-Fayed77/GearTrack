# 🚗 GearTrack - Vehicle Maintenance Management System

A comprehensive web-based application designed to track, manage, and schedule vehicle maintenance services efficiently. 

## 🛠️ Built With
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL (phpMyAdmin)
* **Environment:** XAMPP / Localhost

## ✨ Features
* User Authentication (Login / Register system).
* Track vehicle maintenance history and service logs.
* Schedule upcoming maintenance and repairs.
* Responsive and clean UI for seamless user experience.

## 🚀 How to Run Locally (خطوات التشغيل على جهازك)

To run this project on your local machine, follow these steps:

1. **Clone or Download the Project:**
   * Download the repository as a ZIP file or clone it using Git:
     ```bash
     git clone [https://github.com/Belal-Fayed77/GearTrack.git](https://github.com/Belal-Fayed77/GearTrack.git)
     ```

2. **Move to Local Server Directory:**
   * Copy the project folder and paste it into your local server directory (e.g., `htdocs` folder inside your XAMPP installation path: `C:\xampp\htdocs\`).
   * *Note: Make sure the folder name is `Car_maitanance` or update the path accordingly.*

3. **Start Local Server:**
   * Open **XAMPP Control Panel** and start **Apache** and **MySQL**.

4. **Setup the Database:**
   * Open your browser and go to `http://localhost/phpmyadmin/`.
   * Create a new database for the project (and import your SQL database file if available).

5. **Run the Application:**
   * Open your web browser and navigate to:
     ```text
     http://localhost/Car_maitanance/index.html
     ```
