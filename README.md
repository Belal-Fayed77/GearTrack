# 🚗 GearTrack - Vehicle Maintenance Management System

A comprehensive web-based application designed to track, manage, and schedule vehicle maintenance services efficiently. 

## 🛠️ Built With
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL (phpMyAdmin)
* **Environment:** XAMPP / Localhost

## ✨ Features
* User Authentication (Login / Register system).
* Track vehicle maintenance history and service logs.
* Schedule upcoming maintenance and repairs.
* Responsive and clean UI for seamless user experience.
